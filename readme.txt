Display Kiyoh review widgets on your WordPress site with standard embedded or sticky floating options.

== Description ==

The Kiyoh Review Widget plugin allows you to easily display your Kiyoh reviews on your WordPress website. Choose between a standard embedded widget or a floating sticky widget with a modern glass effect.

**Features:**

* One-click installation and setup
* Standard embedded widget via shortcode
* Sticky floating widget with customizable position
* Modern glassmorphism effect option
* Fully responsive design
* Mobile-optimized with touch support
* Accessibility compliant
* Live preview in admin panel

**Widget Options:**

* Width and height customization
* Color themes (white, black, transparent)
* Multiple language support (English, Dutch, German, French, Spanish)
* Border toggle
* Transparency settings
* Review button visibility

**Sticky Widget Features:**

* Left or right positioning
* Top, middle, or bottom vertical alignment
* Glass (glassmorphism) effect
* Smooth animations
* Click-outside-to-close functionality
* Keyboard navigation support

== Installation ==

1. Upload the `kiyoh-widget` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to 'Kiyoh Widget' in your admin menu
4. Enter your Tenant ID and Location ID from your Kiyoh dashboard
5. Configure your widget appearance and sticky settings
6. Save your settings

To display the widget in your content, use the shortcode: `[kiyoh_widget]`

== Frequently Asked Questions ==

= Where do I find my Tenant ID and Location ID? =

Log in to your Kiyoh dashboard and navigate to the Widget settings. Your Tenant ID and Location ID will be displayed in the widget configuration area.

= Can I use multiple widgets on the same page? =

Yes! You can use the shortcode multiple times with different settings:
`[kiyoh_widget width="300" height="200"]`

= Does the sticky widget work on mobile? =

Yes, the sticky widget is fully responsive and includes touch swipe support for mobile devices.

= Can I customize the widget colors? =

The widget colors are controlled by Kiyoh. You can choose between white, black, and transparent background options in the plugin settings.
